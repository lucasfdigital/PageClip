# Segurança

## Como reportar uma falha

**Não abra uma issue pública.** Reporte de forma privada pelo GitHub:
[Reportar uma vulnerabilidade](https://github.com/lucasfdigital/PageClip/security/advisories/new).

Conte o que encontrou, como reproduzir e qual o impacto. A resposta inicial vem em até 7 dias.

## Versões com suporte

Só a versão mais recente da `main` recebe correções.

## Sobre os dados

O PageClip roda só no seu navegador e não envia capturas para nenhum servidor.
Veja a [política de privacidade](PRIVACY.md).
